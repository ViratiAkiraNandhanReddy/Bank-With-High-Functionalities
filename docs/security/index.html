01 / SCOPE

What security means here.

The project is a learning-oriented desktop simulation, but it still has security properties worth protecting: authentication boundaries, configuration secrets, data integrity, and safe handling of user inputs.

AUTHAuthentication & authorizationCredential flows, admin boundaries, backup codes, and access checks.
DATAExposure & leakageSecrets, local data, generated runtime state, and email credentials.
INPUTInjection & integrityUnsafe inputs, persistence operations, and trust-boundary violations.
CONFIGUnsafe defaultsEnvironment setup, database access, and deployment assumptions.
02 / REPORTING

Keep the first report private.

Do not open a public issue or discussion for a suspected vulnerability. Use the official project contact channels listed on the repository or homepage so maintainers can validate and remediate it before public disclosure.

!
A useful report includes
  • A clear description and affected component
  • Steps to reproduce or a proof of concept
  • Potential impact and attack scenario
  • A suggested mitigation, if known
  • Your preferred contact information
03 / DISCLOSURE

A transparent path to a fix.

01AcknowledgmentThe report is reviewed and acknowledged through the private channel.
02AssessmentImpact, severity, and affected scope are evaluated.
03RemediationA fix or mitigation is developed and tested.
04ReleaseThe security patch is published, followed by an advisory when appropriate.
04 / FOR USERS

Good defaults matter.

Keep currentUse the latest codebase on the default branch and avoid unsupported forks.
Protect secretsNever commit .env, SMTP credentials, database passwords, activation keys, or generated runtime data.
Least privilegeUse dedicated database credentials with only the permissions the environment needs.
Monitor activityUse security events and audit trails when extending or integrating the application.
Important distinction.This project does not process real money or real bank accounts. Reports should describe reproducible software impact.
