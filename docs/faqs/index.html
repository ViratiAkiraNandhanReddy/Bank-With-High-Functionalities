Is this a real banking application?+

No. It is a banking simulation for learning and development. Balances, deposits, withdrawals, transfers, and transaction records are fictional data.

Which operating systems are supported?+

The project is Windows-oriented and uses CustomTkinter plus Windows-specific helpers such as Win32 calls, hPyT, and pywinstyles.

Which database should I start with?+

SQLite is recommended for local development because it requires no separate server. JSON is useful for file-based experiments and MySQL for server-backed scenarios.

Where do I configure the backend?+

Set DATABASE TYPE in database/config.json to SQLite3, JSON, or MySQL. MySQL connection details come from environment variables.

Do I need email settings to run locally?+

No. Email is optional for general exploration, but verification, welcome emails, and password recovery require valid Gmail SMTP settings in .env.

Where should I look before changing a backend?+

Start with the shared contracts in src/__server__/__base__/, then update the matching JSON, SQLite, and MySQL implementations.

How do I report a security issue?+

Do not use a public issue or discussion. Follow the private reporting guidance on the Security page.
