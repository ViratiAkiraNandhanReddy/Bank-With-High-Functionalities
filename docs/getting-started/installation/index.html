Get started / Installation

Install once.
Explore freely.

A clean, repeatable installation path for Windows contributors and curious builders.

⌘ Windows◈ Python 3.15⏱ 5 minutes
ON THIS PAGECloneEnvironmentDependenciesVerify
01 / GET THE CODE

Start with a clean checkout.

Open PowerShell and clone the repository into a folder where you keep development projects.

PowerShell
git clone https://github.com/ViratiAkiraNandhanReddy/Bank-With-High-Functionalities.git
cd Bank-With-High-Functionalities
Why clone?It keeps the docs, assets, Python source, database abstractions, and runtime configuration together.
02 / ISOLATE

Create a virtual environment.

Use a project-local environment so application dependencies do not conflict with other Python work.

PowerShell
py -3.15 -m venv .venv
.\.venv\Scripts\Activate.ps1
If activation is blocked

Run the app with the environment interpreter directly:

.\.venv\Scripts\python.exe main.py
03 / INSTALL

Bring in the runtime.

The runtime manifest includes the desktop UI, image handling, Windows helpers, environment loading, encryption utilities, and optional MySQL connectivity.

PowerShell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
CustomTkinterDesktop interface and themed controls.
PillowImages and application assets.
hPyT + pywinstylesWindows window styling.
MySQL connectorOptional server-backed storage.
04 / CONFIRM

Make sure it is ready.

Run a lightweight import check before starting the full desktop interface.

PowerShell
python -c "import customtkinter, PIL, dotenv; print('Bank.HF environment ready')"
Windows only.The application uses native Windows helpers and is not currently supported on other operating systems.
