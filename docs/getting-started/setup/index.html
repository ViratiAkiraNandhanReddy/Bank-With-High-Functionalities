02 / SECRETS

Keep credentials outside code.

Copy the example file and fill only the variables needed by the backend or workflow you are exploring. Never commit the resulting .env.

PowerShell
Copy-Item .env.example .env
MySQL variables 
MYSQL__DB_USERNAME=
MYSQL__DB_PASSWORD=
MYSQL__DB_HOSTNAME=127.0.0.1
MYSQL__DB_PORTNMBR=3306
MYSQL__DB_CHAR_SET=utf8mb4
MYSQL__DB_DATABASE=bank_with_high_functionalities
03 / OPTIONAL WORKFLOWS

Connect email only when needed.

Welcome messages, email verification, and password recovery use Gmail SMTP over SSL. Email is optional for general local exploration.

.env
SMTP__MAIL_ADDRESS=your-address@example.com
SMTP__APP_PASSWORD=your-gmail-app-password
Use an app password.Do not place a normal account password in project configuration.
04 / FIRST RUN

Activation is part of startup.

When is_activated is false, main.py opens the activation flow. After activation it records launch time and opens sign-in.

01Read configurationShared setup loads environment variables and selects the backend.
02Check activationThe activation interface appears when runtime state says it is incomplete.
03Enter the appSign-in becomes the entry point for user and administrator flows.
