01 / BEFORE YOU BEGIN

Bring the right tools.

This is a Windows-oriented Python 3.15 desktop application. It expects a working graphical session because the UI is built with CustomTkinter and uses Windows helpers for window styling.

Operating systemWindows with a graphical desktop session
RuntimePython 3.15 and PowerShell
NetworkOnly needed for email workflows and external links
StorageSQLite by default; JSON and MySQL are also supported
02 / INSTALLATION

Install locally.

Clone the repository, create an isolated environment, and install the runtime dependencies.

PowerShell
git clone https://github.com/ViratiAkiraNandhanReddy/Bank-With-High-Functionalities.git
cd Bank-With-High-Functionalities

py -3.15 -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install -r requirements.txt
PowerShell policy issue?Skip activation and use .\.venv\Scripts\python.exe main.py directly.
03 / CONFIGURATION

Choose your backend.

The selected persistence implementation is controlled by one value in database/config.json. SQLite is the recommended starting point because it needs no separate service.

ValueBest forData lives in
SQLite3Local development and demosdatabase/sqlite3/
JSONSimple file-based experimentsdatabase/json/
MySQLServer-backed developmentConfigured through .env
database/config.json
{
    "is_activated": false,
    "DATABASE TYPE": "SQLite3"
}

Runtime fields such as activation state and launch time may be updated by the application.

04 / RUNNING

Start the experience.

The startup sequence loads configuration, selects the backend, checks activation, records launch time, and opens sign-in.

PowerShell
python main.py

# or, without activating the environment
.\.venv\Scripts\python.exe main.py
05 / PREVIEW DATA

See the dashboard immediately.

Seed the default SQLite database with fictional users, balances, transactions, security events, and an announcement. The initializer is versioned and safe to run again: DEMO_SEED markers prevent duplicate preview activity.

PowerShell
.\.venv\Scripts\python.exe scripts\init_demo_data.py

06 / FIRST LAUNCH

Know what to expect.

01ActivationThe first run opens product activation when is_activated is false.
02Sign inAfter activation, the application opens user and administrator sign-in.
03ExploreCreate a fictional account, inspect the dashboard, and try simulated transactions.
Simulation only.Balances, deposits, withdrawals, transfers, and transaction records are fictional development data.
Advanced setup notes

For MySQL, create the database named by MYSQL__DB_DATABASE before launching and use a dedicated account with the least privileges required. For email workflows, copy .env.example to .env and configure an app password rather than a normal account password.

  • Install development tooling from etc\requirements-dev.txt when contributing.
  • Run black --check . before opening a formatting-focused change.
  • Treat the SQLite file and runtime config as generated execution state.
