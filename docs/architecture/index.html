01 / SYSTEM LAYERS

Four layers, one direction.

Each layer has a clear responsibility. The presentation layer can evolve without rewriting persistence, while each backend preserves the same behavior behind the scenes.

01PresentationCustomTkinter windows, screens, dashboard tiles, overlays, and administrator views.
02Application servicesAuthentication flows, activation, email workflows, validation, and shared utilities.
03Persistence abstractionThe SERVER namespace exposes authentication, lookup, management, and schema services.
04Storage implementationsJSON files, SQLite, or MySQL selected at runtime.
02 / STARTUP FLOW

What happens at launch?

01Load contextmain.py imports shared configuration, environment variables, and the selected server.
02Check activationIf is_activated is false, the activation interface is shown before sign-in.
03Record launchThe current launch time is written to runtime configuration.
04Open sign-insign_in_interface().sign_in() becomes the first user-facing screen.
03 / THE CONTRACT

Meet SERVER.

UI code calls services through a stable namespace. It should not select a database, construct SQL, or open backend connections directly.

Public service shape
SERVER
├── authentication
│   ├── user
│   └── admin
├── lookup
│   └── user / admin / application / security_event
├── management
│   └── user / admin / application / security_event
└── schema
    └── user / admin / transaction / announcement / security_event

Shared contracts live in src/__server__/__base__/. JSON, SQLite, and MySQL implementations preserve method signatures, return values, and tuple shapes.

05 / CONTRIBUTOR RULES

Keep the boundaries clean.

Reuse the serverUse existing lookup and management methods from the UI instead of duplicating persistence logic.
Update all backendsShared contract changes usually need matching JSON, SQLite, and MySQL implementations.
Protect runtime stateDatabase files and config values are execution state, not disposable source-code fixtures.
Preserve the shapeClass-based namespaces and return formats stay consistent across implementations.
