03 / IMPORTANT NOTES

Know the edges.

Simulation only.This release does not process real money, real bank accounts, or real financial transactions.
Compatibility

The supported environment is Windows with Python 3.15 and a graphical desktop session.

Runtime state

Activation state, launch time, and local SQLite or JSON data are runtime artifacts.
